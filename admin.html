Peer Script

또래상담자 대화 가이드

결과가 나온 뒤 이렇게 이어가요

결과 유형은 정답이 아니라 대화를 여는 질문이에요.

1. 결과 화면의 유형 이름과 설명을 함께 읽어요. — "이거 보니까 어때요, 좀 맞는 것 같아요?"
2. 화면에 제시된 질문으로 대화를 열어요. (라인별 "대화 시작 멘트" 참고)
3. 판단하거나 조언하려 하지 말고, 2~3분 정도 들어주는 데 집중해요.
4. 대화를 마무리하며 카드에 맞는 아이템을 건네요. — "이거 가져가서 오늘 하루 떠올려봐요."
Tone

어떤 느낌으로 이야기할까

기본 태도

진단이 아니라 대화를 여는 도구예요. 맞다/틀리다로 판단하지 말고 "이런 면이 있을 수 있겠다" 정도로 가볍게 전달해주세요.

말투

존댓말이지만 편하게. "~하셨나요" 보다는 "~했어요?, ~그랬죠?" 처럼 또래끼리 이야기하듯 자연스럽게 말해주세요.

침묵 다루기

질문을 던진 뒤 바로 다음 말을 잇지 말고 2~3초 기다려주세요. 대답을 안 해도 괜찮고, 그냥 다음으로 넘어가면 돼요.

선 지키기

조언하거나 해결하려 하지 마세요. 들어주는 것만으로 충분해요. 더 깊은 이야기가 나오면 1388 같은 전문기관 연계를 안내해주세요.

Scoring

결과는 어떻게 나오나요

6문항 중 가장 많이 겹치는 보기가 오늘의 유형이에요

각 카드는 6개의 질문으로 구성돼 있고, 질문마다 4개의 보기(A~D)가 있어요. 참가자가 고른 보기 중 가장 많이 선택된 보기가 "오늘의 유형"으로 나와요. 예를 들어 6개 중 3개를 A, 2개를 B, 1개를 C로 골랐다면 A 유형 결과가 나오는 식이에요.

유형은 성격을 규정하는 게 아니라 "오늘, 지금 이 순간" 어디에 더 가까운지를 보여주는 거예요. 같은 사람이 다음에 다시 해도 다른 유형이 나올 수 있어요 — 이 점을 참가자에게 살짝 알려주면 "정답을 찾아야 한다"는 부담을 덜어줄 수 있어요.

Type Scripts

유형별 해석 & 멘트 가이드

💗 나를 얼마나 사랑하고 있을까 4개 유형
A · 엄격한 코치형

스스로에게 너무 높은 기준을 들이대며 잘한 것보다 부족한 것을 먼저 보는 상태예요. 그만큼 열심히 살아왔다는 뜻이기도 해요.

"이 유형 보면, 스스로한테 되게 엄격하게 살아온 것 같아요. 그만큼 열심히 해왔다는 뜻이기도 하거든요."
질문: "요즘 나 자신한테 가장 많이 하는 말이 뭐예요?"
전달: "오늘 하루는 그 기준 살짝 내려놓고, 이 응원카드 보면서 나한테 다정한 말 한번 해줘요."
B · 눈치보는 거울형

자기 기준보다 남의 시선이 먼저 떠오르는 상태예요. 맞춰주려다 보면 내가 뭘 원하는지 뒤로 밀려나요.

"다른 사람 시선에 많이 맞춰온 편인 것 같아요, 그러다 보면 내가 뭘 원하는지 놓치기 쉽잖아요."
질문: "다른 사람 시선 말고, 진짜 내가 원하는 건 뭐예요?"
전달: "이 카드 가져가서, 오늘만큼은 내 마음이 먼저라고 생각해봐요."
C · 다정한 친구형

스스로에게 너그럽고 실수해도 다시 일어설 힘을 믿는 상태예요. 이미 좋은 자기돌봄 습관을 갖고 있어요.

"스스로를 꽤 잘 돌보고 있는 편이네요. 이런 태도 유지하는 것도 쉽지 않은 건데."
질문: "요즘 스스로를 잘 돌본 순간이 있었다면 뭐예요?"
전달: "지금처럼만 하면 돼요. 이 카드는 그 다정함 잊지 말라는 의미로 드릴게요."
D · 무심한 방관자형

나에 대한 생각 자체를 잘 안 하는 상태예요. 괜찮아서가 아니라 챙길 여유나 습관이 없었을 수도 있어요.

"나한테 별로 신경 안 쓰고 지내온 것 같아요. 바빠서 그랬을 수도 있고요."
질문: "오늘 하루, 나를 위해 한 게 있다면 뭐예요?"
전달: "이 카드 보면서 하루에 한 번이라도 나를 떠올리는 연습 해봐요."
🔥 요즘 너무 지쳐있어 4개 유형
A · 과열형

할 일 생각이 머릿속을 떠나지 않는 상태예요. 쉬는 순간에도 다음 일이 떠올라 진짜 쉼이 어려웠을 거예요.

"할 일이 머릿속에서 계속 돌아가는 것 같아요, 쉬어도 진짜 쉬는 게 아니었겠어요."
질문: "요즘 할 일 목록에서 하나만 빼도 된다면 뭘 뺄래요?"
전달: "이 모찌 만지작거리면서, 잠깐이라도 할 일 생각 내려놔봐요."
B · 억눌림형

불편하거나 힘든 걸 표현하기보다 속으로 삭이는 편이에요. 괜찮아 보여도 쌓인 게 많을 수 있어요.

"힘든 걸 잘 참아온 편인 것 같아요. 그만큼 속으로 쌓인 것도 많았을 텐데."
질문: "요즘 참고 있는 말이 있다면 뭐예요?"
전달: "이 모찌한테라도 가끔 털어놔요, 괜찮아요."
C · 방전형

의욕이 없는 건 게을러서가 아니라, 이미 많이 쓴 에너지가 채워지지 않은 상태예요. 지금은 회복이 먼저예요.

"에너지가 많이 소진된 상태 같아요. 게으른 게 아니라 정말 많이 썼던 거예요."
질문: "요즘 조금이라도 힘이 났던 순간이 있었어요?"
전달: "오늘은 애쓰지 말고, 이 모찌처럼 그냥 말랑하게 쉬어도 돼요."
D · 예민형

신경이 곤두서 있어서 평소라면 넘겼을 일에도 쉽게 반응하게 돼요. 몸과 마음이 계속 경계 상태예요.

"요즘 작은 일에도 신경이 많이 쓰이는 상태인 것 같아요."
질문: "요즘 유난히 신경 쓰이는 게 뭐예요?"
전달: "이 모찌 꾹꾹 누르면서 긴장 좀 풀어봐요."
🌙 혼자인 것 같은 기분이 들어 4개 유형
A · 군중속고립형

관계는 있지만 진짜 내 얘기를 나눌 사람은 없다고 느끼는 상태예요. 겉으로는 잘 지내는 것처럼 보일 수 있어요.

"사람은 많은데 진짜 마음 터놓을 사람은 없는 느낌인 것 같아요."
질문: "사람은 많은데 진짜 얘기할 사람은 누구예요?"
전달: "이 키링 보면서, 오늘 여기서 나눈 이 대화도 그런 연결 중 하나라고 생각해줘요."
B · 단절형

연락하고 만나는 관계 자체가 줄어든 상태예요. 혼자가 익숙해졌지만, 그만큼 연결이 그리운 순간도 있을 거예요.

"요즘 관계 자체가 좀 줄어든 것 같아요. 혼자가 익숙해졌어도 가끔은 그립잖아요."
질문: "요즘 누구랑 가장 자주 연락해요?"
전달: "이 부적 가지고 있다가, 연락하고 싶은 사람 생기면 먼저 톡 한번 보내봐요."
C · 소외형

모임이나 관계 안에 있어도 내 자리가 아닌 것 같은 느낌이 드는 상태예요. 소속감이 부족하게 느껴질 수 있어요.

"어딘가에 있어도 내 자리가 아닌 것 같은 느낌 받을 때 있죠."
질문: "어디에 있을 때 가장 나답게 느껴져요?"
전달: "이 키링은 당신 자리가 분명히 있다는 의미로 드릴게요."
D · 그리움형

지금 상황보다, 예전에 있던 어떤 사람·관계의 부재가 외로움의 중심인 상태예요. 그 관계가 남긴 자리가 클 수 있어요.

"지금보다는 예전의 누군가가 많이 생각나는 상태 같아요."
질문: "요즘 가장 그리운 사람이 있다면 누구예요?"
전달: "그 그리움도 소중한 마음이에요. 이 키링 가지고 가서 가끔 떠올려줘요."
🌫️ 미래가 막막하고 불안해 4개 유형
A · 비교형

내 속도보다 남들의 속도가 기준이 되어버린 상태예요. 비교하다 보면 지금의 나는 늘 부족해 보일 수 있어요.

"남들이랑 많이 비교하게 되는 시기인 것 같아요."
질문: "요즘 누구랑 자꾸 나를 비교하게 돼요?"
전달: "이 키캡 뽑은 것처럼, 각자 속도는 랜덤이에요. 당신 속도대로 가면 돼요."
B · 길없음형

뭘 해야 할지 몰라서 막막한 상태예요. 방향이 없다는 건 틀렸다는 뜻이 아니라, 아직 못 찾았다는 뜻이에요.

"방향 자체가 잘 안 보이는 상태인 것 같아요. 못 찾은 거지 틀린 게 아니에요."
질문: "요즘 조금이라도 관심이 가는 게 있다면 뭐예요?"
전달: "이 키캡처럼, 아직 안 열어본 선택지가 많이 남아있어요."
C · 완벽압박형

틀릴까봐, 실패할까봐 시작 자체가 어려운 상태예요. 완벽하게 하려는 마음이 오히려 발을 묶고 있을 수 있어요.

"실패할까봐 시작을 못 하고 있는 상태 같아요."
질문: "작게 시도해볼 수 있는 한 가지가 있다면?"
전달: "완벽한 선택 아니어도 괜찮아요. 이 키캡도 랜덤으로 뽑는 거잖아요."
D · 무기력형

미래 생각 자체가 버거워서 자꾸 미루거나 피하게 되는 상태예요. 지금은 몰아붙이기보다 잠깐의 쉼이 필요해요.

"미래 생각하는 것 자체가 버거운 상태인 것 같아요."
질문: "요즘 아무 생각 없이 쉰 적이 있어요?"
전달: "오늘은 그냥 이 키캡 받아가는 걸로 충분해요, 애쓰지 않아도 돼요."
Operations

운영 체크리스트

사전 설정 (행사 며칠 전)

  • config.js에 실제 Supabase URL·anon key 입력 확인
  • 참가자 페이지에서 4개 카드 전부 직접 한 번씩 완료해보고, 관리자 "참여 통계" 탭에 숫자가 올라오는지 확인
  • GitHub Pages 배포 상태 확인 (Settings → Pages에 "Your site is live" 표시)
  • 관리자 페이지 주소는 운영진끼리만 공유 (별도 로그인 보호 없음)

부스 세팅 (당일)

  • 참가자 QR코드 인쇄해서 부스 전면에 비치 (관리자 페이지 상단 "QR코드 보기/인쇄")
  • 또래상담자용 기기에서 참가자 페이지 미리 열어 네트워크·화면 상태 확인
  • 4가지 아이템(응원카드·카피바라 모찌·응원 부적 키링·랜덤 키캡) 각 라인별로 분리 배치
  • 또래상담자 전원에게 운영 가이드(톤·결과 해석·유형별 멘트) 미리 공유 및 숙지
  • 상담이 길어질 경우를 대비해 대기 줄 또는 번호표 준비

운영 중 체크

  • 검사는 "맞다/틀리다"가 아니라 "대화 소재"라는 점을 먼저 안내
  • 한 명당 5~7분 내로 진행 (검사 1분 + 대화 2~3분 + 전달 1분)
  • 깊은 고민을 꺼내는 경우, 전문기관 연계 안내(1388 등) 준비해두기
  • 아이템 소진 시 바로 보충할 수 있도록 여분 챙기기
  • 관리자 페이지 "참여 통계"는 수시로 새로고침해서 라인별 쏠림 확인 (특정 아이템 소진 속도 예측)

마감 후

  • 관리자 페이지 "참여 통계"에서 전체/카드별 최종 인원 캡처해서 기록 보관
  • 남은 아이템 수량 파악 및 다음 행사용 재고 메모
  • 다음 행사에서도 같은 기록을 이어 쓸지, "기록 초기화"로 새로 시작할지 운영진과 상의 후 결정
